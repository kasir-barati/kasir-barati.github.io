If you need a solid template for your Golang project you can use my repo: github.com/Ponos-OS/golang-template

Before Go 1.21, checking if a slice contained a specific value required writing a manual for loop. It worked, but it was:

  • Verbose.
  • Repetitive
  • Prone to subtle bugs (like looping incorrectly or forgetting to return early).
  • Hard to read

And to automate them you just need the golangci-lint tool. This is what I usually do.
